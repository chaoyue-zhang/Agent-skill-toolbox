# 每日硬科技简报 (daily-tech-brief)

每日汇总硬科技领域要闻，输出结构化简报。

## 覆盖领域

- 半导体
- EDA / 工业软件
- 汽车电子
- 工业自动化（EPLAN 等）

## 输出规格

- 每日 10 条：国内 6 条 + 国际 4 条
- 文末附综合评述
- 每期需覆盖 8 个定向话题中的至少 1 条
- 输出路径：`/workspace/YYYY-MM-DD-每日科技简报.md`

## 参数

| 参数名 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| date | string | ❌ | 简报日期，默认当天 |
| focus | string | ❌ | 重点话题，逗号分隔 |

## 注意事项

- 国内 / 国际配比固定 6:4，不要随意调整。
- 涉及中国香港、中国澳门、中国台湾时，表述须合规。
